# AndroidPythonMonitor

Android-приложение с локальным Python 3.13 через Chaquopy. Это прозрачный диагностический инструмент: он показывает сведения об устройстве, получает последнюю известную геопозицию только после нажатия и разрешения Android, а системную камеру открывает только по отдельному нажатию. Фонового сбора, скрытой съёмки и сетевой отправки данных в проекте нет.

## Состав

- Kotlin: интерфейс и вызовы Android API.
- Python (`app/src/main/python/report.py`): форматирование сведений об устройстве.
- Chaquopy 17.2.0: запуск Python внутри Android-приложения.
- `minSdk 24`, `targetSdk 35`, `compileSdk 36`.
- ABI: `arm64-v8a` и `x86_64`.

## Получение APK без Android Studio

Сборка выполняется GitHub Actions в облаке.

1. Распакуйте ZIP на компьютере.
2. Создайте пустой репозиторий на https://github.com/new (не добавляйте README, license или .gitignore при создании).
3. Загрузите **содержимое** папки `AndroidPythonMonitor` в репозиторий, сохранив структуру папок. В частности, папка `.github/workflows` и файл `build-apk.yml` должны попасть в репозиторий.
4. Откройте вкладку **Actions** репозитория. Если GitHub предложит включить Actions, разрешите их.
5. Выберите **Build Android APK** и нажмите **Run workflow**. Также сборка автоматически запускается после отправки изменений в ветку `main` или `master`.
6. Дождитесь зелёного статуса. Откройте завершённый запуск и скачайте артефакт **AndroidPythonMonitor-debug-apk** внизу страницы.
7. Распакуйте скачанный артефакт. Файл для установки называется `app-debug.apk`.

Если вкладка Actions не показывает workflow, проверьте, что файл находится именно по пути `.github/workflows/build-apk.yml` в корне репозитория.

## Сборка локально

Требуются JDK 17, Android SDK Platform 36, Build Tools 36.0.0 и Gradle 8.13. Откройте корневую папку проекта в Android Studio и дождитесь синхронизации Gradle. Затем выполните задачу `:app:assembleDebug`. APK появится по пути `app/build/outputs/apk/debug/app-debug.apk`.

## Разрешения и поведение

- Геолокация запрашивается только при нажатии соответствующей кнопки. Android показывает системный запрос разрешения.
- Используется последняя известная позиция; это не гарантирует получение свежего GPS-измерения.
- Кнопка камеры запускает установленное системное приложение камеры. Приложение не делает скрытых снимков.
- Данные в проекте не отправляются на сервер.
